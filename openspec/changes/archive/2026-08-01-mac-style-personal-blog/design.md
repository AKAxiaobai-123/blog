## Context

当前仓库为空，没有既有代码或技术栈约束。用户需要从零搭建一个个人博客，要求风格简易耐看、导览清晰简单，并参考 macOS / Apple 的视觉语言。博客内容应低维护、易写作，因此采用 Markdown 文件管理内容，并构建为静态站点。

除 macOS 基调外，用户希望加入年轻风格的内容，并以首页“叠放卡片 + 鼠标聚焦流动 + 点击展开”的 demo 先行验证；同时博客要有明确主题，首页以故事线组织，其他内容后续再定。

用户提供了明确的视觉参考：Firefly 博客主题（https://firefly.cuteleaf.cn/）。该主题使用 Astro + Tailwind，特征是绿松石主色（hue 165）、全宽 banner、16px 圆角卡片、毛玻璃吸顶导航、深浅双主题和卡片化信息面板。本设计吸收其清新质感，但保持“把日子叠起来”的叙事主题与叠放卡片交互。

## Goals / Non-Goals

**Goals:**

- 提供首页、文章、归档、关于四类核心页面和一致的全局导航。
- 以 Markdown 文件作为唯一内容源，静态生成站点。
- 建立可复用的 macOS / Apple 风格设计规范（色彩、字体、毛玻璃、圆角、间距、暗色模式）。
- 提供首页年轻风格 Demo：叠放卡片、鼠标移动聚焦流动、点击展开内容，快速验证视觉与交互方向。
- 定义博客演示主题“把日子叠起来”，并以首页故事线呈现。
- 参考 Firefly 的清新视觉：绿松石主色、全宽 banner、大圆角卡片、毛玻璃顶栏与深浅双主题。
- 支持响应式布局、SEO 基础信息和 RSS。

**Non-Goals:**

- 不做评论系统、用户登录、后台管理或数据库。
- 不做富文本编辑器、实时协作或复杂动效。
- 不做营销式落地页或仿 macOS 窗口/Dock 的皮肤化设计。
- 不做重 3D、物理模拟或整页沉浸式动效，保持静态博客的轻量与耐看。
- Demo 不引入完整内容体系、用户数据或全站年轻化改造，先保持首页验证范围。

## Decisions

### 使用 Astro 作为静态站点生成器

Astro 适合内容优先的博客：Markdown/MDX 一等公民、默认零 JS、输出静态文件，部署简单。备选方案：Next.js（功能强但偏重）、VitePress（偏文档站）、纯 HTML（文章维护成本高）。

### 内容使用 Astro Content Collections

文章放在 `src/content/posts/`，通过 frontmatter 定义 `title`、`description`、`date`、`tags`、`draft` 等字段，并用 schema 校验；阅读时长根据正文字数计算。写文章只需新增 Markdown 文件。

### 路由结构

- `/`：首页，展示站点简介和最新文章。
- `/posts`：文章列表页。
- `/posts/<slug>`：单篇文章，含目录和前后篇导航。
- `/archive`：按年份分组的归档页。
- `/about`：关于页。
- `/rss.xml`：RSS 输出。
- `/404`：未找到页面。

### 设计系统用 CSS 自定义属性实现

`tokens.css` 定义颜色、字体栈、间距、圆角、阴影、毛玻璃参数。参考 Firefly 后调整为：主色为绿松石（`--config-hue: 165`，约 `oklch(.7 .14 165)`），背景与卡片在浅色、深色下各有一套变量；字体使用系统字体栈（参考 Roboto/system-ui）；卡片使用 16px 大圆角，小控件保持 8px 圆角；顶栏使用半透明背景和 `backdrop-filter: blur()`，不支持时回退为实色背景。

### Firefly 风格参考

- 全宽首页 banner：高度约 65vh，背景图与主题句叠加，移动端收缩并保证文字可读。
- 卡片化布局：文章、演示卡片和信息面板共享同一套卡片令牌（背景、边框、圆角、阴影）。
- 侧边信息面板：站点统计、分类、标签以卡片组件呈现，宽屏时 sticky 跟随内容，窄屏时在正文后堆叠。
- 毛玻璃吸顶导航：顶栏半透明、模糊、边框极细，滚动后保持可见。
- 深浅双主题：通过 `html[data-theme]` 与系统偏好切换，所有颜色来自令牌。
- 页面宽度宽松（参考 `100rem` 级页面宽度），但正文行宽仍限制在 70-80 字符。

### 暗色模式

默认跟随 `prefers-color-scheme`，提供手动切换按钮；手动选择写入 `localStorage` 并覆盖系统偏好。

### 全局导航

顶部固定导航包含首页、文章、归档、关于四个入口，当前页高亮；移动端保持同序可用，点击目标高度不小于 44px。

### 主题与首页故事线

博客演示主题定为“把日子叠起来”：叠放卡片隐喻每一天像一层薄薄的记录，鼠标划过时焦点像翻阅记忆一样流动。首页按“引子 → 互动卡片 → 最新文章 → 归档入口”组织：引子先给出主题句，叠放卡片演示区是第一个互动章节，最新文章对应“今天的一层”，最后以“过去的日子”归档入口收尾。

### 年轻风格首页 Demo（叠放卡片）

首页导航下方演示区使用 4-6 张占位卡片叠放，默认错位露出层次；鼠标在卡片区域内移动时，通过 `requestAnimationFrame` 更新 CSS 自定义属性（如 `--deck-x`、`--deck-y`、`--focus-index`），让光效和高亮跟随指针，并让靠近指针的卡片轻微上浮。点击卡片仍通过原生 `<details name="demo-card">` 展开详细内容，同一时间只展开一张。触屏设备与无 JS 环境降级为纵向列表或可滚动列表；`prefers-reduced-motion` 下禁用位移动画。年轻风格通过强调色、活泼排版和轻量动效呈现，但继续使用设计令牌与 8px 内圆角，避免与 macOS 基调割裂。

### 侧边信息面板与归档筛选

首页、文章列表和归档页共享一个右侧信息面板：站点统计展示文章数、分类数、标签数和总字数，全部在构建期由 Content Collections 计算；分类和标签按文章数量排序，点击后跳转到 `/archive/?category=<名称>` 或 `/archive/?tag=<名称>`。归档页是纯静态输出，由页面内轻量脚本读取查询参数、按 `data-category` / `data-tags` 过滤并展示当前筛选条件与清除入口。面板在 1024px 以上使用 `sticky` 固定，小于该宽度时在主内容之后纵向排列，移动端不产生横向溢出。

## Risks / Trade-offs

- 当前环境无法直连 `github.com` → 推送、部署可能需代理或镜像；开发阶段使用本地预览和 npm 镜像即可继续。
- Astro 依赖安装可能受网络影响 → 使用 `registry.npmmirror.com` 等可用镜像。
- `backdrop-filter` 兼容性 → 通过 `@supports` 提供实色背景回退。
- 鼠标移动事件高频触发 → 用 `requestAnimationFrame` 节流，仅在卡片区域 hover 时更新。
- 触屏设备没有 hover → 叠放效果降级为纵向列表或可滚动列表，内容仍可展开。
- 故事线章节过长会冲淡“简易耐看” → 每章保持短文案和明确出口，不做长页式堆叠。
- 大圆角与原有 macOS 克制约束存在张力 → 用户明确参考 Firefly，设计系统以 16px 卡片圆角为基准，并保持圆角令牌全局一致。
- 全宽 banner 若没有合适素材会显空 → 先用渐变或纹理占位并允许后续替换真实图片。
- 内容字段不一致 → 用 Content Collections schema 校验并在 CI 中构建验证。

## Migration Plan

仓库当前无提交。在 `dev` 分支完成脚手架、页面和设计规范，本地构建与预览验证后，提交首个版本；发布时合并到 `main` 并部署到静态托管平台。回滚策略：删除/还原对应页面提交。
