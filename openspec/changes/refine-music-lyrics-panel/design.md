## Context

多次改版后，音乐条仍占用顶栏空间且交互不符合预期。参考图是顶栏音符图标 + 弹出式歌曲卡片（HOYO-MiX 风格），用户希望按此重做：图标常驻右上角，点击弹出，再点收回。

实现约束：Astro 静态站点、无新增依赖、移动端不溢出、无脚本可降级。

## Goals / Non-Goals

**Goals:**

- 顶栏右上角只保留 44px 音符图标，默认不显示任何音乐区域。
- 点击图标弹出歌曲卡片，带动效；再点图标、点击外部或 Esc 收回。
- 卡片包含封面、歌名/歌手、歌词行、进度条+时间、等大的三个控制键。
- 播放、切歌、进度、歌词与恢复状态行为不回归。
- `prefers-reduced-motion` 下无动画。

**Non-Goals:**

- 不做歌词滚动、音量、播放列表或循环模式。
- 不做常驻进度条或折叠歌词条。

## Decisions

### 音符图标触发按钮

顶栏右侧放置 44px 圆形音符按钮，`aria-expanded`/`aria-controls` 指向弹出卡片；播放中图标使用强调色提示状态。默认无额外布局占用。

### 弹出卡片

卡片 `position: absolute` 对齐触发按钮右下，宽度约 21rem（移动端 `calc(100vw - 32px)`）。收起态 `opacity: 0`、`visibility: hidden`、`scale(0.96) + translateY`；展开态过渡回正常，形成弹出动效。

### 关闭方式

点击图标切换、点击卡片外部关闭、Esc 关闭；避免弹窗遮挡顶栏其他控件。

### 控件与播放逻辑

上一首/播放/下一首同尺寸（28px 视觉，44px 点击目标），播放/暂停、进度拖拽、歌词更新与 localStorage 恢复沿用现有脚本逻辑。

## Risks / Trade-offs

- 弹窗遮挡页面内容 → 默认收起，且可点击外部/Esc 快速关闭。
- 移动端弹窗过宽 → 使用视口约束宽度并右对齐，不产生横向溢出。
- 用户可能期望常驻进度 → 本期按用户要求完全隐藏，仅图标触发。

## Migration Plan

按顺序更新 `MusicPlayer.astro`、`SiteHeader.astro`、`global.css` 与 `tasks.md`，执行 `npm run build` 并验证桌面、移动端、暗色、无脚本与减少动效，随后提交并推送 `dev`。回滚方式：还原音乐组件与样式提交。
