## Why

仓库目前是空项目，需要从零搭建一个个人博客。用户希望博客风格简易耐看、导览清晰简单，并参考 macOS / Apple 的视觉语言，因此需要先建立明确的页面范围和设计规范，避免后续实现时方向漂移。

在耐看的 macOS 基调之外，博客还需要加入年轻风格的内容和可交互的首页体验。本轮先以一个小 demo 验证“卡片式轮播 + 点击展开”的方向，其他内容待定，确认后再迭代。

进一步确认方向后，demo 升级为叠放卡片：鼠标移动时焦点与光效跟随流动，点击卡片展开内容；同时博客需要一个明确的主题，首页用故事线串起引子、互动卡片和文章，让访客更有沉浸感。

## What Changes

- 新增首页：站点简介、最新文章列表、导航入口，作为博客的第一落点。
- 新增文章页：Markdown 正文渲染、日期/分类/阅读时长等元信息、文章内目录、上一篇/下一篇切换。
- 新增归档页：按年份分组的文章时间线，方便快速回顾。
- 新增关于页：个人简介、联系方式、站点说明。
- 新增全局导航：首页、文章、归档、关于四个入口，移动端与桌面端保持清晰一致。
- 新增设计规范：以 macOS / Apple 风格为基调，明确色彩、字体、毛玻璃质感、圆角、间距、暗色模式等规则。
- 新增年轻风格首页 Demo：在导航下方提供叠放式交互卡片，鼠标移动时聚焦光效跟随流动，点击卡片可展开内容。
- 新增博客主题：以“把日子叠起来”作为演示主题，贯穿首页引子、章节标题和结尾入口。
- 新增首页故事线：按“引子 → 互动卡片 → 最新文章 → 归档入口”的顺序组织首页，形成有起承转合的浏览路径。
- 博客内容使用 Markdown 文件管理，构建为静态站点，无数据库和后台依赖。

## Capabilities

### New Capabilities

- `home-page`: 首页的展示内容、文章摘要与导览入口。
- `article-page`: 单篇文章的正文渲染、元信息、目录与前后篇导航。
- `archive-page`: 按时间归类的文章归档展示。
- `about-page`: 关于页的简介与联系方式展示。
- `site-navigation`: 全局导航结构、当前页状态与响应式行为。
- `mac-style-design-system`: macOS / Apple 风格的设计规范与主题实现。
- `youthful-home-demo`: 首页年轻风格叠放卡片、鼠标聚焦流动与点击展开交互的演示能力。
- `home-storyline`: 首页故事线布局与博客主题叙事的呈现能力。

### Modified Capabilities

无既有能力需要修改。

## Impact

- 全新静态博客站点，不影响任何既有代码。
- 技术方向：静态站点生成器 + Markdown 内容 + 少量前端交互。
- Demo 范围：叠放卡片与故事线仅作用于首页，使用占位内容，后续再决定是否推广到全站。
- 构建与部署：支持静态托管平台（如 GitHub Pages / Vercel / Netlify）。
- 分支策略：`dev` 作为开发分支，后续发布内容再合并到 `main`。
