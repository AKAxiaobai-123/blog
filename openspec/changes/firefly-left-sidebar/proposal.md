## Why

右侧 Firefly 风格信息面板已经上线，但宽屏页面左侧仍是空白单栏，整体布局不如参考主题那样有“作者在场感”。补上左侧信息栏后，首页、文章与归档页的宽屏布局更均衡，也更贴近 Firefly 的双侧信息结构。

## What Changes

- 新增左侧信息面板，包含作者卡片（头像占位、昵称、简介、关于与 GitHub 入口）、公告卡片（欢迎语 + “了解更多”）、快捷导航（文章、归档、关于、RSS）。
- 宽屏（>=1280px）下，首页、文章列表和归档页改为“左栏 + 主内容 + 右栏”三栏布局。
- 1024-1279px 保持“主内容 + 右栏”，左侧栏隐藏，避免内容过挤。
- 小于 1024px 时，左右面板按顺序堆叠在主内容之后，不产生横向溢出。
- 左侧面板复用现有卡片令牌：16px 圆角、细边框、轻阴影、深浅双主题与毛玻璃质感。
- 头像先使用占位视觉（渐变底 + 首字母），后续可替换为真实图片。

## Capabilities

### New Capabilities
- `site-left-sidebar`: 左侧信息面板（作者简介、公告、快捷导航）及其响应式布局能力。

### Modified Capabilities

无现有能力需要修改。

## Impact

- 新增组件 `src/components/LeftPanel.astro`，并在首页、文章列表、归档页接入三栏布局。
- 更新 `src/styles/global.css` 的三栏网格、左侧面板与移动端堆叠样式。
- 不改动内容模型、依赖或构建方式，保持纯静态站点。
