## Context

当前博客已经完成右侧 Firefly 风格信息面板（站点统计、分类、标签），宽屏页面为“主内容 + 右栏”布局。参考站点 Firefly 在页面左侧还有作者资料、公告、站点信息等卡片。用户希望左侧栏也按同样的视觉风格补齐，让宽屏布局更像参考主题，同时保持博客“简易耐看、导览清晰”的原则。

实现约束：Astro 静态站点、无新增运行时依赖、内容仍由 Markdown 管理，所有颜色与圆角复用现有设计令牌。

## Goals / Non-Goals

**Goals:**

- 新增左侧信息面板：作者卡片（头像占位、昵称、简介、关于/GitHub 入口）、公告卡片、快捷导航卡片。
- 首页、文章列表和归档页在宽屏下呈现“左栏 + 主内容 + 右栏”三栏布局。
- 保持现有右侧面板行为不变，移动端不产生横向溢出。

**Non-Goals:**

- 不引入 Firefly 的音乐播放器、日历、评论等复杂 widget。
- 不在文章详情页加入双侧栏，避免与目录布局冲突。
- 不做真实头像资源、用户系统或后台配置。

## Decisions

### 左侧面板内容采用轻量三卡

参考 Firefly 左侧结构，但只保留与个人博客直接相关的模块：作者卡片、公告、快捷导航。备选方案是完整复刻资料、公告、音乐、站点信息四卡；考虑到博客目前没有音乐与日历数据，保留空 widget 会破坏“简易耐看”，因此不采用。

### 三栏断点与堆叠顺序

- `>=1280px`：显示左栏、主内容、右栏，左栏 `sticky` 跟随滚动。
- `1024-1279px`：隐藏左栏，保持主内容 + 右栏，避免平板宽度下内容过窄。
- `<1024px`：左右面板均堆叠到主内容之后，右栏在前、左栏在后，页面无横向滚动。

备选方案是移动端完全隐藏侧栏；为了让作者介绍和公告仍可访问，选择堆叠展示。

### 组件与数据来源

新增 `src/components/LeftPanel.astro`，作者昵称、简介、公告文案先以组件内静态内容维护，头像使用渐变底 + 首字母占位；后续可替换为图片与内容集合。快捷导航直接链接到 `/posts`、`/archive`、`/about`、`/rss.xml`。

### 视觉一致性

左侧卡片复用 `--color-card`、`--color-border`、`--radius-md`、`--shadow-sm` 等令牌，与右侧面板共用同一套 16px 圆角卡片样式和深浅主题。

## Risks / Trade-offs

- 三栏会压缩主内容宽度 → 主列使用 `minmax(0, 1fr)`，正文行宽仍由现有令牌限制，不产生文字溢出。
- 移动端页面变长 → 面板卡片保持紧凑间距，堆叠顺序稳定。
- 快捷导航与顶栏导航重复 → 作为侧边快捷入口保留，方便滚动场景下的跳转。

## Migration Plan

新增 `LeftPanel.astro` 与三栏网格样式，替换首页、文章列表、归档页的内容网格，构建验证后提交并推送 `dev`。回滚方式：还原上一版两栏布局提交。
