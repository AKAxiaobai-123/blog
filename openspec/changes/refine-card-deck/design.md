## Context

当前首页演示区使用“鼠标移动聚焦流动 + 紧凑层叠”交互，用户反馈视觉拥挤、选择方式不明显，内容也只有纯文字。参考 Firefly 的卡片化展示，用户希望改为：底部缩略图负责切换卡片，当前卡片左图右文，其余卡片松散立体地收纳在后方。

实现约束：Astro 静态站点、无新增依赖、沿用现有设计令牌，移动端与无脚本环境仍可用。

## Goals / Non-Goals

**Goals:**

- 底部缩略图条：悬停或点击缩略图切换当前卡片，激活态清晰。
- 当前卡片“左图右文”：宽屏图左文右，窄屏图上文下。
- 非当前卡片松散 3D 叠放：明显错位、轻透视、不紧凑。
- 保留详情展开、减少动效与无脚本降级。

**Non-Goals:**

- 不做轮播自动播放或拖拽排序。
- 不引入真实图片资源管理、上传或数据库。
- 不改变左右侧栏与其他页面布局。

## Decisions

### 缩略图条作为唯一切换入口

在卡片区域底部渲染 `<ul class="deck-thumbs">`，每项是一个 `button`，包含迷你视觉预览与序号。支持 `hover: hover` 的设备上悬停即切换；所有设备都支持点击与键盘激活。备选方案是保留点击叠放卡片切换，但用户明确要求缩略图，且叠放卡片作为装饰更稳定。

### 当前卡片两栏内容

主卡片使用 CSS Grid，宽屏 `minmax(0, 1.1fr) minmax(0, 1fr)`，左视觉右文字；窄屏单列，视觉在上。视觉先由每张卡片的 `visual` 字段渲染为基于强调色的 CSS 纹理占位，后续可替换为真实图片；`alt` 文案随卡片标题生成。

### 松散立体叠放

非当前卡片绝对定位于舞台内，通过 `perspective`、`rotateX/rotateY`、`translate` 与递减 `z-index` 形成松散层叠，偏移量明显大于当前紧凑实现（约 28-48px），`pointer-events: none`。`prefers-reduced-motion` 下只保留静态层叠。

### 交互脚本替换

删除原 `requestAnimationFrame` 指针跟随逻辑，改为简单的 `activate(index)`：更新主卡片内容、激活态与缩略图高亮；无 JS 时直接渲染纵向卡片列表。

### 数据模型

`src/data/demo.ts` 的 `DemoCard` 增加 `visual: string` 与 `imageAlt: string`，视觉占位值按卡片强调色命名，实施时先由 CSS 生成纹理。

## Risks / Trade-offs

- 3D 变换可能造成边缘溢出 → 舞台保留足够内边距与 `overflow: hidden`，移动端不启用 3D 叠放。
- 悬停切换在触屏设备上会误触发 → 仅在 `(hover: hover)` 时绑定 hover 事件。
- 占位视觉可能显得空 → 使用强调色 + 纹理标签组合，并明确标注为演示。
- 展开按钮与缩略图并存可能混淆 → 展开/收起只作用于当前卡片文字区，缩略图只负责切换。

## Migration Plan

按顺序更新 `demo.ts`、`DemoDeck.astro` 与 `global.css`，构建并验证桌面、平板、移动端与暗色模式，随后提交并推送 `dev`。回滚方式：还原上一版演示区提交。
